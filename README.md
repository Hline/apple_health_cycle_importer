# 🍎 애플 건강 생리주기 일괄 등록기 (Apple Health Cycle Importer)

다른 캘린더나 생리주기 추적 앱에서 백업한 **CSV / TXT 생리주기 기록**을 **아이폰 애플 건강(Apple Health, HealthKit)**에 단 몇 초 만에 일괄 등록할 수 있는 도구입니다.

> 🔒 **100% 오프라인 & 개인정보 보호**: 모든 텍스트 및 파일 처리는 사용자의 브라우저 로컬 환경에서만 동작하며 외부 서버로 전송되지 않습니다.

---

## 🤔 왜 이 변환기가 필요할까요? (애플 건강의 등록 원리)

### 1. 일반 앱의 기록 방식 vs 애플 건강의 저장 규격 불일치
* **일반 캘린더/생리 앱**: `2026-10-18 ~ 2026-10-25`처럼 **"시작일과 종료일"의 기간(Range)**으로 1줄에 묶어서 기록합니다.
* **애플 건강(Apple Health, HealthKit)**: 애플 건강에는 '기간'으로 한 번에 생리를 넣는 입력 방식이 **없습니다**.  
  대신 **매일매일 하루 단위(Daily Sample)**로 각각 등록해야 합니다:
  ```text
  2026-10-18  --> [월경 샘플 기록]
  2026-10-19  --> [월경 샘플 기록]
  2026-10-20  --> [월경 샘플 기록]
  ... (8일간 하루씩 8번 등록)
  ```
  연속된 날짜 샘플들이 쌓이면 애플 건강 내부 엔진이 이를 자동으로 하나의 '생리 주기'로 판정하여 주기 분석 및 가임기/예정일을 계산합니다.

### 2. 수작업의 한계 & 이 변환기가 해결하는 것
* 만약 2년 치(약 23~24회 주기) 데이터를 아이폰 건강 앱에서 직접 입력하려면, **달력을 넘겨가며 약 180~200일의 날짜를 일일이 손으로 200번 터치**해야 합니다.
* 본 변환기는 `start, end` 2개 열만 있는 주기 목록을 넣으면 **애플 건강이 필요로 하는 185개의 일별 날짜 리스트로 0.1초 만에 자동 분해**해 줍니다. (단축어에 복사-붙여넣기 1번으로 3초 만에 완료!)
* 💡 `duration`(기간) 컬럼은 파일에 없어도 시작일과 종료일로 자동 계산되므로 생략 가능합니다.

## ⚡ 빠른 시작 (3단계)

### 1. 전용 iOS 단축어 추가
아이폰에서 아래 링크를 눌러 **생리주기 일괄 등록 단축어**를 추가하세요:

👉 **[iOS 단축어 1초 만에 추가하기 (iCloud 링크)](https://www.icloud.com/shortcuts/c8ca5ec405284a969554c024248be16f)**

---

### 2. 생리주기 데이터 변환 및 복사
웹페이지([GitHub Pages 바로가기](https://hline.github.io/apple_health_cycle_importer/))에 접속하여 소장하고 계신 CSV/TXT 파일을 업로드하거나 텍스트를 붙여넣습니다.

애플 건강은 생리 기록을 **하루 단위 샘플(Daily Sample)**로 저장하므로, 시작일과 종료일 사이의 모든 날짜를 자동으로 일별 리스트로 변환해 줍니다. 변환 후 **[📋 일별 날짜 텍스트 전체 복사하기]**를 누릅니다.

---

### 3. 아이폰 단축어 실행
1. 아이폰에서 추가한 **단축어**를 실행합니다.
2. 텍스트 입력창이 나타나면 복사한 날짜 텍스트 전체를 **붙여넣기**하고 [완료]를 누릅니다.
3. 건강 데이터 쓰기 권한을 최초 1회 **[허용]**하면, 수백 일치의 생리 기록이 애플 건강에 자동으로 모두 등록됩니다! 🎉

## 📑 지원하는 CSV / TXT 샘플 양식

한 줄에 **[시작일]**과 **[종료일]**이 포함되어 있으면 쉼표(`,`), 물결(`~`), 탭(`Tab`) 구분자를 모두 자동으로 파싱합니다.

### ① 한국어 날짜 형식 (CSV)
```csv
start,end,duration
2026년 10월 18일,2026년 10월 25일,8일
2026년 09월 20일,2026년 09월 27일,8일
```

### ② 표준 하이픈 / 점 형식 (CSV)
```csv
start_date,end_date,flow
2026-10-18,2026-10-25,보통
2026.09.20,2026.09.27,많음
```

### ③ 자유 텍스트 형식 (TXT)
```text
2026-10-18 ~ 2026-10-25
2026년 9월 20일 ~ 2026년 9월 27일
2026.08.21, 2026.08.28
```

## 💻 Python CLI 사용법

터미널이나 콘솔 환경에서 직접 변환하고 싶으신 경우:

```bash
python convert_cycles.py sample_menstrual_cycles.csv
```

실행 후 생성되는 `apple_health_dates.txt` 파일의 내용을 복사하여 단축어에 입력하시면 됩니다.
